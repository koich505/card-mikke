# UF-011 — テーマ別プリセット検索

Status: Implemented in UI Mock v1.2
Date: 2026-10-06
Traceability: FR-040、AC-041、SCR-PUB-001、UIR-HOME-004

## Goal

未登録・登録利用者が公開中テーマを1回選ぶだけで、Account登録や追加入力を挟まず、年間利用額を含む条件一式を適用した検索結果へ到達する。

## Flow

1. ホームで公開中テーマを表示順に確認する。
2. テーマを1回選択し、対応する検索結果へ遷移する。
3. 選択テーマ、年間利用額、利用先内訳、今回検索限定・Profile非更新を確認する。
4. 必要に応じて`条件を変更する`から通常検索画面へ戻り、個別条件を変更して再検索する。
5. 結果では通常検索と同じ算定・Rankingを使用し、テーマ名による優位性を保証しない。

## Exception

非公開または不明なテーマIDを直接指定しても条件を適用せず、テーマ名を開示しない。通常条件検索へ進める案内を表示する。

## Boundary

Profile、Cookie、Browser storage、API、DBを更新しない。Fixtureは合成データで、テーマ適用は初期表示用のReact状態だけに反映する。
