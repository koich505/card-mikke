# Frontend Quality Checklist

- [ ] 承認済みMockと主要状態に適合する
- [ ] Desktop / Mobileと主要Viewportを確認した
- [ ] Keyboard、Focus、Semantic、Label、Contrastを確認した
- [ ] Loading / Empty / Error / Partial / Unknownを確認した
- [ ] Metadata、Index、Canonical、Structured DataをApplicableに応じ確認した
- [ ] UI変更をScreenshotまたは承認済み方法で比較した
