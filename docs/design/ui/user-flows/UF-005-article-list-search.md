# UF-005: 特集記事一覧の検索と絞り込み

Status: UI Mock v0.6
Requirements baseline: FR-041 / AC-043

## Goal

利用者が公開済みの特集記事をフリーワード、記事種別、タグから探し、更新確認中の旧記事を最新情報と誤認せず記事詳細へ進める。

## Main flow

1. 利用者がHeaderまたはホームから`特集記事`へ進む。
2. キーワード、記事種別、タグを指定する。タグを複数選んだ場合は、すべて含む条件であることを確認する。
3. 件数と適用中条件を確認し、新着順または更新順で記事を探す。
4. 更新確認中の記事では、公開済み旧記事であり公式情報の確認が必要なことを確認する。
5. 記事Cardから記事詳細へ進み、関連するカード詳細または条件付き検索結果へ進む。

## Alternative states

- 0件: 条件は自動変更せず、条件の変更または全解除を選べる。
- 条件解除: キーワード、種別、タグ、並び順を初期状態へ戻す。
- Mobile: Cardは1列、すべての選択ControlはKeyboard操作可能とする。

## UI-only boundary

合成Fixtureだけを使用する。検索・FilterはBrowser Memory内で完結し、外部送信、永続化、Analyticsは行わない。
