# UF-008: 掲載範囲・サイト方針

## Goal

利用者が掲載範囲、算定、更新、広告・Affiliate、免責を確認し、全件網羅や保証と誤認しない。

## Main flow

1. HeaderまたはFooterから`/policy`へ進む。
2. 合成Coverage数、集計単位、対象・未対応範囲、最終確認日を確認する。
3. 算定の入力、公式Source、対象外、仮定を確認する。
4. 更新・訂正、広告・Affiliateと順位の分離、非保証を確認する。
5. 必要に応じてLogin不要の誤情報指摘へ進む。

## Boundary

数値はUI検証用合成値。外部通信、Analytics、実Coverage集計、法的判断を行わない。

Traceability: FR-019、FR-027、AC-015、AC-019、AC-038、NFR-LEGAL-001〜002
