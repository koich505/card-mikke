# Requirements Scope

Status: Draft  
Last updated: 2026-08-10

## Purpose

本サイトは、日本国内で個人向けクレジットカードを探す利用者が、自身の属性、利用目的、利用サービス、想定する年間利用状況に合うカード候補へ短時間で到達し、納得して選択できるようにする。

単なるカード一覧ではなく、利用者が指定した条件に基づく検索と、想定利用状況における便益の比較を提供価値の中心とする。

## Primary Value

- 初めてクレジットカードを作る個人が、自分に合う候補を見つけられる。
- ポイント、特典、利用サービス等を重視する個人が、条件を指定して候補を絞り込める。
- 想定する1年間の使い方に基づき、どのカードが相対的に有利かを判断する材料を得られる。
- 検索に加え、利用目的や読者像に応じたおすすめ記事、および単一カードの新商品・機能特集記事から候補や商品の特徴を発見できる。

初期Releaseにおける「お得」は、利用者が入力した年間利用額と明示した仮定を基に、ポイント等の金銭換算可能な還元と年会費から算出する年間正味還元額の目安を中心に判定する。実際の利用明細を再現する確定額ではない。保険、ラウンジ等の金銭換算しにくい便益は、この数値評価に含めない。

「最短」はSuccess Conditions、「網羅的」はCoverage開示、金銭換算範囲は`02-functional-requirements.md`の算定要件に従って判定する。残る未決事項は`05-open-questions.md`で管理する。

## Initial Release Scope

### Included

- 日本国内の個人向けクレジットカード情報
- カードごとの券面デザイン画像と、その対応条件・Source・利用許諾情報
- 日本国内で個人が申し込める、現在新規受付中のクレジットカードを通常検索の主対象とする
- 利用者の属性、利用目的、重視するポイント・特典、利用サービス等を条件とするカード探索
- 想定する年間利用状況に基づくカード候補の比較
- 利用者登録と、年間利用額・利用先別金額等を再利用するためのProfile保持
- Profile値の検索・比較条件への自動反映、および利用時の手入力・上書き
- 未登録利用者による手入力での検索・比較
- 登録利用者向けの条件保存および履歴利用
- 用途または読者像別のおすすめ記事の公開
- 単一カードを対象とする、新商品、機能、特典または変更内容の特集記事の公開
- 運営者向けの記事投稿・編集機能
- 保持するカード情報を利用した記事案の自動生成と、公開までの運用
- 公式Sourceの変更検知、再確認、更新案作成、運営者承認後の情報更新
- 公式SourceからのAI支援による初回・継続データ収集、項目候補の構造化、差分抽出
- カード会社等の申込先へ遷移するAffiliate Linkによる収益化

### Excluded from Initial Release

- 法人カード
- 家族・追加カードを主対象とする探索
- デビットカード
- プリペイドカード
- BNPLその他の後払いサービス
- カードレス購買決済

家族・追加カードは独立した商品検索対象にはしないが、対象となる個人向けカードの付随情報として、有無と確認可能な条件を表示し、発行可能な個人向けカードへ絞り込む条件として使用できる。その他の対象外商品が個人向けカードのEligibility、Benefitまたは利用条件に関係する場合の表示範囲は、個別の機能要件で検討する。

## Future Candidates

初期Releaseで対象外とした法人カード、家族・追加カード、デビット、プリペイド、後払いサービスおよびカードレス購買決済は、将来候補とする。採用時期と優先順位は未決とする。

## Success Conditions

- 利用Test参加者の80%以上が、検索開始から3分以内に比較可能な候補を3件以上見つけられる。
- 掲載会社数、掲載カード数、現在新規受付中として確認できたカード数、および最終確認日を測定・公開できる。
- 「国内すべてを網羅している」と断定せず、掲載対象とCoverageの限界を説明する。
- 初期公開時点で国内すべての対象を掲載することを完了条件とせず、未対応範囲を開示しながらCoverageを段階的に拡大できる。

## Domain Constraints

- 未確認の市場Factや商品条件を補完して「最適」と判定しない。
- `unknown`、`undisclosed`、`partially_disclosed`、`disclosed`を保持する。
- Domain SpecificationのOpen Questionを、検索条件、比較条件または固定分類として推測で確定しない。
- お得さの比較では、Member RewardとPartner Revenue Shareを混同しない。
- 保険、ラウンジ等の非金銭評価を年間正味還元額へ加算しない。
- Campaign、Fee Rule、Reward Ruleの適用条件、期間、対象者、上限および確認時点を無視して計算しない。
- カテゴリ内最良条件、年間額の月次均等利用、取引単位の概算等、計算に使用した仮定を表示する。
- Product LifecycleとFeature Lifecycleを混同せず、確認時点や適用期間を考慮する。
