# Users and Goals

Status: Draft  
Last updated: 2026-08-10

## Priority Users

### U-001: 初めてクレジットカードを作る個人

- Priority: Primary
- Problem: 商品や条件が多く、自分に合うカードを判断しにくい。
- Goal: 自身の属性、利用目的、重視する条件に合う候補へ到達し、違いを理解して選択する。

### U-002: ポイント・特典・利用サービスを重視する個人

- Priority: Primary
- Problem: 還元や特典の条件が複雑で、自身の利用状況における便益を比較しにくい。
- Goal: 想定する年間利用状況と重視条件に基づき、相対的に有利な候補を把握する。

### U-003: 用途別の記事から候補を探す個人

- Priority: Primary
- Problem: 自分で多数の検索条件を設定する前に、利用目的や生活上の関心に合う候補を知りたい。
- Goal: 用途または読者像別のおすすめ記事を入口として、選定理由を確認しながら候補を発見する。

### U-004: 特定カードの特徴や新情報を知りたい個人

- Priority: Primary
- Problem: 新しいカードや既存カードの機能・特典について、公式情報に基づく要点をまとめて把握しにくい。
- Goal: 単一カードの特集記事を通じて、対象カードの特徴、変更点、適用条件および根拠を理解する。

## Primary User Goals

- 自分の属性に適合しうる個人向けクレジットカードを探す。
- ポイント、特典、利用サービス等の条件から候補を絞り込む。
- 1年間の想定利用状況における便益を候補間で比較する。
- 年間利用額や利用先別金額をProfileへ保存し、検索・比較へ再利用する。
- Profileから反映された条件を必要に応じて手入力で変更する。
- 用途別の記事を通じて候補と選定理由を知る。
- 単一カードの新商品、機能、特典または変更内容を扱う特集記事から、そのカードの特徴と根拠を知る。
- 情報の根拠、確認時点および不明点を踏まえて判断する。

## Provisional Scenarios

以下は方向性を確認するための仮説であり、機能要件やUIを確定しない。

1. 初めてカードを作る利用者が、自身の属性と重視条件を指定し、申込候補を絞り込む。
2. 利用者が年間の利用額や利用先を指定し、費用と便益を考慮した候補を比較する。
3. 利用者が用途別のおすすめ記事を読み、掲載理由と商品情報を確認して候補を検討する。
4. 利用者が単一カードの新商品・機能特集記事を読み、特徴、適用条件、確認時点および公式Sourceを確認する。
5. 運営者が保持するカード情報を基に記事案を生成し、内容と根拠を確認して公開・更新する。
6. 登録利用者が年間利用額と利用先別金額をProfileへ保存し、検索時に自動反映された値を確認・変更して比較する。
7. 未登録利用者が条件を手入力して検索・比較し、条件保存または履歴利用が必要になった時点で登録する。

Profileへ保存する属性、年間正味還元額の算定範囲、および記事の公開・更新責任は機能要件に従う。記事の具体的な分類・表現はUI Mock工程へ渡す。
