# 1. research-scope.md — 調査範囲と境界

## 1.1 目的
本コーパスは、日本国内で「申込み・保有・利用されている」クレジットカードおよび隣接するカード型後払い商品について、事業者・商品・契約・条件・例外を証拠付きで整理するものである。データモデル（テーブル名・カラム名・JSON構造・Enum・ORM等）の確定は目的外とする。

## 1.2 Core / Adjacent の区分

| 区分 | 定義 | 法的根拠・位置付け |
|---|---|---|
| Core | 国際ブランド（Visa/Mastercard/JCB/Amex/Diners等）を伴う一般的なクレジットカード。割賦販売法上の「包括信用購入あっせん」に該当[^1] | 経済産業省への登録が必要（割賦販売法31条）[^1] |
| Adjacent | 国際ブランドなしハウスカード、BNPL、少額包括信用購入あっせん型、家賃保証立替連携、カード型ローン、デポジット型、バーチャル専用後払い、プリペイド・デビットハイブリッド | 個別信用購入あっせん、二月払購入あっせん（無登録）、少額包括信用購入あっせん（緩和登録）等、契約形態により法的扱いが異なる[^2][^3][^4] |

Observation / Evidence: BNPLは法律上の統一概念ではなく、狭義には「コンビニ後払い」型を指し、広義にはクレジット払いも含む。割賦販売法上、購入時から2ヶ月を超えない範囲で弁済する場合（二月払購入あっせん）は登録不要であり、多くの国内BNPL事業者（Paidy、atone等）がこの類型で運用されている。[^5][^2][^4]

Design Implication: Core/Adjacentを同一エンティティとして扱わず、「後払い契約の与信区分（包括/個別/二月払）」を別軸のプロパティとして持たせる設計判断があり得る（本コーパスでは判断のみ提示、確定はしない）。

## 1.3 対象外・除外方針
プリペイドカード・通常デビットカードは原則除外だが、クレジットとの境界事例（例: Kyash Card=Visaプリペイド+後払い機能混在）は記録する。[^6][^7]

# 2. regulatory-market-map.md — 規制・母集団マップ

## 2.1 監督体制
- 割賦販売法に基づき、包括信用購入あっせん業者・個別信用購入あっせん業者は経済産業省の登録簿へ登録が必要（同法31条、35条の3の23）。[^2]
- 令和8年7月末現在、登録包括信用購入あっせん業者は240社（うち認定業者4社）。[^1][^8]
- 登録個別信用購入あっせん業者は令和8年7月末現在139社。[^9]
- 2020年法改正（2021年4月施行）により、極度額10万円以下の「少額包括信用購入あっせん業者」制度が新設され、登録要件が緩和（利用者支払可能見込額の算定のみ義務）。[^3][^10]

Observation / Evidence: 登録事業者数と国際ブランド発行会社数は一致しない。登録は法的資格の付与であり、実際に一般消費者向けカードを発行しているかは別問題である（例: 地銀系カード会社の多くはJCBグループ加盟の発行代行として登録されているのみで、独自の一般消費者向け商品展開は限定的な場合がある）。[^11]

Design Implication: 「登録事業者」テーブルと「消費者向け商品発行主体」テーブルを混同しない設計判断が有効（本コーパスでは示唆のみ）。

## 2.2 業界団体
一般社団法人日本クレジット協会は2026年2月1日現在、会員904社（正会員461社、準会員443社）。過去（2018年10月時点）は929社（正会員377社、準会員552社）であり、時系列で会員構成が変化している。[^12][^13]

Disclosure status: disclosed（公式サイト記載） / Confidence: high

Observation / Evidence: 日本クレジット協会は「国内のクレジットカード発行会社の入会率100%」と自称するが、これは発行会社の会員化率であり、母集団＝カードイシュアという仮定を裏付けるものではない（大手加盟店等の非イシュアも会員として含まれる）。[^13]

## 2.3 BNPL・少額後払いの規制動向
金融庁の割賦販売制度WGでは、BNPLが過剰与信の入口となるリスクや悪質加盟店による悪用実態が指摘され、法規制の要否が議論されている（2024年10月時点の事務局資料）。2026年8月時点で包括的なBNPL専用法制は未成立であり、既存の割賦販売法の枠内（二月払購入あっせん扱い等）で運用されている実態が続く。[^14]

Confidence: medium（規制動向は変化しうるため） / Disclosure status: disclosed

## 2.4 役割分類の例（母集団調査における混同回避）

| 役割 | 説明 | 例 |
|---|---|---|
| Issuing / Member contract | カード会員契約主体 | 各カード発行会社 |
| Credit underwriting | 与信審査主体 | JACCS、オリコ等信販会社が代行するケースあり |
| Billing | 請求・収納代行 | カード会社本体または委託先 |
| Card manufacturing/issuing operation | 物理カード製造・発行実務 | 大日本印刷等（詳細未調査） |
| Brand licensing | 国際ブランドライセンス | Visa/Mastercard/JCB/Amex |
| Acquiring | 加盟店契約 | 三井住友カード、GMOペイメントゲートウェイ等 |
| Processing | 決済処理 | NTTデータ、日本カードネットワーク等（未確認） |
| Co-brand partner | 提携先企業 | ANA、JR、大学等 |
| Affinity partner | アフィニティ団体 | 大学生協、専門職団体 |
| Reward operator | ポイント運営 | 永久不滅ポイント（クレディセゾン）等 |
| Guarantee company | 保証会社 | 家賃保証連携における保証会社 |

Design Implication: 一社が複数役割を持つ場合（例: JCBはブランドライセンサーかつ自社発行イシュアでもある）を単純な1:1マッピングで表現しない方が良いという示唆のみ提示。[^11]

# 5. representative-products.md — 代表商品の詳細調査

## 5.1 三井住友カード（NL） / 三井住友カード ゴールド（NL）
- 発行・契約主体: 三井住友カード株式会社[^15]
- 国際ブランド: Visa、Mastercard（デュアル発行対応）[^37]
- 商品バリエーション: ナンバーレス仕様、一般/ゴールド/プラチナ各券種でデュアル発行可能。三井住友カードプラチナプリファードはVisaのみでデュアル発行対象外。[^38]
- 年会費: デュアル発行時の2枚目年会費はゴールド2,200円（税込）、プラチナ5,500円（税込）等、券種別に異なる。[^43]
- 申込経路: 新規申込時に「VISAカードとマスターカードの2枚」を選択、または既存会員が異なるブランドを追加申込することで自動的にデュアル発行扱いとなる。[^37][^38]
- 大学連携: 大学生協が三井住友カード（NL）を推奨カードとして案内、大学生協店舗利用でポイント2倍。[^30][^25]
- Disclosure status: disclosed / Confidence: high
- Retrieved date: 2026-08-07

## 5.2 JCBゴールド ザ・プレミア
- 発行主体: 株式会社ジェーシービー[^27]
- 商品位置付け: JCBゴールド会員向けの完全招待制上位カード
- 招待条件: JCB ORIGINAL SERIES対象のJCBゴールド利用額が2年連続100万円（税込）以上、または1年で200万円（税込）以上[^27]
- 招待スケジュール: 2026年の招待は終了、次回招待は2027年3月中旬予定（本会員へEメール案内、申込期間3月中旬～5月中旬）[^27]
- 年会費: サービス年会費（家族会員無料、条件達成で本会員も免除あり）はJCBゴールド年会費とは別建て[^27]
- Disclosure status: disclosed（招待条件は公開） / Confidence: high
- Retrieved date: 2026-08-07

## 5.3 アメリカン・エキスプレス・ゴールド系（招待日和特典）
- 発行主体: アメリカン・エキスプレス・インターナショナル,Inc.日本支社[^44]
- 特典: 「ゴールド・ダイニング by 招待日和」は2名以上予約で1名分コース料理無料。A期間（4-9月）・B期間（10-3月）で各1店舗1回、年最大2回[^23][^45]
- プラチナは「2 for 1 ダイニング」で年会費165,000円、ゴールド/プリファードは33,000円/39,600円[^23]
- 招待制上位カード（ゴールドプリファード）: 既存ゴールド会員への招待により昇格可能（招待条件は非公開）[^31][^46]
- Disclosure status: partially_disclosed（招待の具体的基準は非公開） / Confidence: medium
- Retrieved date: 2026-08-07

## 5.6 Paidy（BNPL代表事業者）
- 事業形態: 二月払購入あっせん相当（無登録運用）に分類される可能性が高い一方、規制動向next-genとして少額包括信用購入あっせん登録の余地がある[^4]
- 支払方式: 翌月一括払い、または3～36回の分割（口座振替・銀行振込）[^4]
- 与信: 購入履歴等をもとにしたAIスコアリング。年収等に基づく伝統的与信ではない[^10]
- Disclosure status: partially_disclosed（内部スコアリングロジックは非公開） / Confidence: medium
- Retrieved date: 2026-08-07

# 9. research-gaps.md — 未調査領域とカバレッジ評価

## 9.1 明確に不足している調査領域
- 専門職団体カード（医師・弁護士・税理士等の職能団体発行カード）の実例
- ホテル系提携カードの具体的商品（例: 帝国ホテル、星野リゾート等との提携有無）
- ゲーム／エンタメ提携カード（アニメ・声優・球団ファンクラブ系）の商品構造
- 暗号資産連携カードの国内実例（海外のCrypto.comカード等の日本展開有無を含む）
- シニア・年齢条件型カード（若年層限定の反対側）の実例
- パーチェシングカード（購買特化法人カード）の日本市場での商品名・契約構造
- カード製造・発行実務（Card manufacturing/issuing operation）を担う専業ベンダーの特定
- 決済処理（Processing）を担う主体の役割別整理（NTTデータ、CAFIS等の詳細）
- デポジット型カード（消費者向け）の日本での実例有無の確定的検証
- 個別カード会社ごとの締日・支払日・ポイント集計期間・端数処理ルールの体系的収集（本ラウンドでは代表数社のみ）

## 9.2 Coverage Matrixに基づく網羅度評価
Coverage Matrix（Section 6）において「？（未調査）」および「▲（Tier4のみ）」に分類されたセルが、Issuer Type × Product Typeで約35%、Reward Mechanism × Product Typeで約40%を占める。したがって本調査は「網羅した」と言える状態ではなく、特に以下の3領域で構造的な調査不足が残る。

1. 専門職・アフィニティ団体系カードのTier1-3情報が体系的に不足している。
2. BNPL事業者の内部審査・与信ロジックはほぼ全事業者で非開示であり、一次情報での裏付けに構造的限界がある。
3. カード発行の実務的役割分担（製造・プロセッシング）の主体特定が本ラウンドでは大きく手薄である。

## 9.3 現時点で発見できていない可能性が高い商品類型・事業者類型
- 医師会・弁護士会等の専門職団体発行または提携のクレジットカード
- スポーツ球団・アーティストファンクラブ提携カードの具体的商品名
- 暗号資産取引所と提携したクレジットカード（国内発行）
- ホテルブランド単独提携カード（航空・鉄道に比べ発見が手薄）
- デポジット型（担保金predepositを前提とする）消費者向けクレジットカードの現存する商品
- カード製造・パーソナライズ印刷を専業とするベンダー企業
- 少額包括信用購入あっせん業者として新規登録された、消費者向け一般カードを発行していない専業BNPL事業者の全リスト（経済産業省登録簿の全件精査は未実施）
